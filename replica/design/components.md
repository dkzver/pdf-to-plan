# Компоненты клона

Плотный десктопный интерфейс: 13/18 базовый текст, элементы 24–28 px по высоте, радиусы 3–5 px, тени почти не используются (границы важнее). Иконки — Lucide (MIT), 16 px, stroke 1.6, `currentColor`. Шрифт — Inter с системным фолбэком; оригинальный Swing-шрифт не воспроизводим и не нужен.

Все размеры — из `tokens.css`. Ни один компонент не задаёт сырой hex.

## Меню-бар

```
Меню-бар
  варианты    Файл, Правка, Мебель, План, 3D вид, Справка
  размеры     высота 26px, пункт 13px/18px, паддинг 8px по горизонтали
  состояния   обычный, наведение (surface-2), открыто (surface-2 + рамка border), недоступный (text-muted, 45%)
  токены      bg surface, text text, border border
  a11y        role="menubar", пункты — кнопки с aria-haspopup, открытие с Enter/Space, закрытие Esc, стрелки между пунктами
  экраны      S01
```
