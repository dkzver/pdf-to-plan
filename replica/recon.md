# Карта реконструкции: Sweet Home 3D 7.5 (desktop, Java/Swing; веб-демо как вторичный источник)

Область клонирования: ядро продукта — рисование плана (стены, комнаты) → расстановка мебели из каталога → живой 3D-вид → сохранение/печать/рендер.
Для кого: собственная реализация редактора планировки в проекте Sweet Home 3D.
Дата: 2026-11-19

## Ядро цикла

Пользователь рисует стены на плане в масштабе, ставит мебель из каталога и сразу видит результат в 3D — файл дома сохраняется локально и выводится в PDF/картинку/3D-формат.

## Потоки

```
F01 Нарисовать план дома
    S01 -> S02 (стены) -> S03 (комнаты) -> S01
    happy path: 3 клика до первой стены, двойной клик — завершение
    edge: незамкнутый контур, стена поверх стены, смена масштаба по ходу, отмена Esc

F02 Обставить комнату
    S04 (категория/поиск) -> перетаскивание на план -> S06 (размеры, поворот)
    happy path: 2 действия на предмет
    edge: перетаскивание за пределы плана, поворот на 15°, предмет «утоплен» в стену, скрытая мебель

F03 Посмотреть результат в 3D
    S01 (3D-вид) -> S10 (настройки) -> навигация/виртуальный визит
    happy path: 1 действие
    edge: стены закрывают обзор, прозрачность стен, вид изнутри, потолок включён/выключен

F04 Сделать рендер
    S01 -> S11 (качество, свет, время суток) -> сохранение PNG
    happy path: 4 действия
    edge: ночной свет, низкая память, отмена рендера

F05 Записать видео-облёт
    S01 -> S12 -> сохранение
    edge: длительность, прерывание, размер файла

F06 Напечатать/экспортировать план
    S01 -> S13 (масштаб, формат) -> PDF
    edge: план не влезает на страницу, несколько уровней, колонтитулы

F07 Импортировать свою мебель
    S14 (файл, масштаб, категория) -> S04 -> перетаскивание -> S06
    edge: модель без текстур, слишком большой масштаб, нестандартная ориентация

F08 Разложить дом по уровням
    S09 (добавить уровень, подъём, высота) -> S01 -> S02/S04 на другом уровне
    edge: мебель с нижнего уровня, скрытие уровня, лестница между уровнями
```

## Вне области клонирования

- Библиотека из 1 600+ моделей и 400 текстур, каталог Sweet Home 3D — лицензированный контент, не переносится; нужен свой открытый набор.
- Название, логотип, иконки приложения, тексты справки и локализации — чужие ассеты.
- Плагины на Java и сторонние расширения — экосистема, не функция.
- Формат `.sh3d` как совместимость с чужими файлами: читать можно только публично описанную структуру, приватные детали не копируем; на старте — свой формат.
- Облачные аккаунты, онлайн-менеджер, мобильные версии — отдельные продукты.
- Физика освещения и фотореалистичный движок уровня оригинала — берём открытый рендерер, а не воспроизводим их рендер.

## Оценка

Экранов 17, потоков 8, сущностей 7. Сложные части: интерактивное редактирование плана с привязками и размерами; синхронный 3D-вид и камера; материалы по частям модели; рендер фото/видео; многоуровневый дом. Размер: **L** (квартал), если урезать до плана + каталога + 3D-вида без рендера — **M**.

Следующий шаг: `/replica-architect` — стек, схема БД, порядок сборки.
