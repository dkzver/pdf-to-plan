# pdfplan — разбор PDF-чертежа в схему стен

Прототип конвейера «PDF → стены → правка человеком». Без ML: геометрия берётся из
операторов PDF или из растра, затем склеивается и чистится правилами.

## Что делает

1. Определяет, векторная страница или растровая.
2. Вектор: залитые прямоугольники и толстые линии → стены; белые «подчистки» →
   проёмы (окно, если внутри 2+ тонкие линии).
3. Растр: 300 dpi → порог → скелет → карта расстояний → Hough → толщина.
4. Склеивает коллинеарные, двойные линии, вставки; сводит узлы; убирает дубли.
5. Пишет `plan.json`, `overlay.svg`, `page.png` и автономный `viewer.html`.

## Команды

```bash
python tools/pdfplan/fixtures.py                 # тестовые PDF + эталон
python tools/pdfplan/cli.py путь/к/плану.pdf     # разбор, --page 1, --dpi 300, --force vector|raster
python tools/pdfplan/evaluate.py tools/pdfplan/fixtures/truth.json <каталог>/plan.json
python tools/pdfplan/make_viewer.py <каталог>    # план + страница -> viewer.html
```

Зависимости: PyMuPDF, OpenCV (с `ximgproc`), numpy. Больше ничего не требуется.

## Формат plan.json

```json
{
  "page_size": {"width": 842, "height": 595},
  "classification": {"kind": "vector", "used": "vector", "drawings": 25},
  "units": "pt",
  "walls": [{"a": [100, 100], "b": [700, 100], "thickness": 12, "confidence": 0.95, "source": "vector"}],
  "openings": [{"kind": "window", "a": [195, 100], "b": [285, 100], "width": 16}],
  "stats": {"walls": 7, "junctions": 5, "median_thickness_pt": 12}
}
```

Единицы — пункты PDF. Перевод в метры — по калибровке (стена известной длины или
размерное число), в прототипе не реализован.

## Публикация

Две разные вещи, не путать:

1. **Просмотрщик — статика.** `viewer.html` самодостаточен: внутри JSON и картинка,
   внешних запросов нет. Его можно положить на GitHub Pages, Netlify, Vercel или любой
   веб-сервер и открывать по ссылке. Разбор при этом не работает — только просмотр и правка.
2. **Разбор — Python-сервис.** `server.py` (FastAPI + PyMuPDF + OpenCV). Ему нужен хост
   с Python, не Node. Локально — `python tools/pdfplan/server.py`. В контейнере:

```bash
docker build -t pdfplan tools/pdfplan
docker run -p 8791:8791 -v pdfplan_out:/app/out pdfplan
```

Для Render / Fly / Railway: репозиторий с `tools/pdfplan` как контекстом, стартовая
команда `uvicorn server:app --host 0.0.0.0 --port $PORT`. Память — от 1 ГБ на воркер
(PyMuPDF и OpenCV), одновременно разбирать лучше 1–2 файла.

Что нужно добавить перед публичным доступом: лимит размера на прокси, таймаут запроса
(разбор A3 — 1–7 с), очистка `out/` старше суток, HTTPS и простая авторизация, если
чертежи клиентские.

## Сервис с загрузкой

```bash
python tools/pdfplan/server.py          # http://127.0.0.1:8791
python tools/pdfplan/server.py 9000     # другой порт
```

Страница: «Выбрать PDF» или перетащить файл → «Разобрать» → через 5–10 секунд
открывается просмотрщик с этим документом. Файлы не покидают машину: результат
лежит в `tools/pdfplan/out/<id>/` (`plan.json`, `page.png`, `overlay.svg`,
`rooms.json`). Ссылка «Другой PDF» возвращает к загрузке.

## Просмотрщик

`viewer.html` автономный: внутри JSON и картинка страницы. Тянуть концы, клик по
стене — выбрать, Del — удалить, «Стена» + два клика — добавить, Ctrl+Z — отменить,
«Пересчитать комнаты» — площади в м² по текущей геометрии, «Скачать JSON» — экспорт.
Красные кружки — разрывы контуров, зелёные метки — комнаты и площади.

## Проверено

| вход | precision | recall | толщина | осевая |
| --- | --- | --- | --- | --- |
| векторная фикстура | 1.00 | 1.00 | 0.0 pt | 0.0 pt |
| растровая фикстура (200 dpi) | 1.00 | 1.00 | 0.1 pt | 0.1 pt |
| реальный ARCHICAD-план | — | — | покрытие площади 104% | — |

Фикстуры синтетические и чистые — это верхняя граница, не обещание для реальных
сканов. Ограничения и план развития: `docs/pdf-to-plan.md`.

## Тестовый набор

```bash
python tools/pdfplan/bench_cases.py   # 7 кейсов: двойные линии, штриховка, цвет, сканы, мультистраница
python tools/pdfplan/bench.py         # прогон + таблица tools/pdfplan/bench/report_auto.md
```

Результаты и разбор поломок: `tools/pdfplan/bench/report.md`. Коротко: векторные
конвенции — 1.00/1.00, скан 200 dpi — 0.78/1.00, скан с наклоном 1.5° — 0.67/0.86.

## Остальные модули

- `scale.py` — масштаб по размерным числам (на реальном листе дал 1:50, 45 подтверждений).
- `rooms.py` — комнаты заливкой: стены + закрытые проёмы, площади в м².
- `render_check.py` — наложение результата на страницу.
